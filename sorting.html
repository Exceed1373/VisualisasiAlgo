Nama Algoritma Best Case Average Case Worst Case Space Complexity Karakteristik & Stabilitas

Selection Sort O(n²) O(n²) O(n²) O(1) Tidak stabil, meminimalkan jumlah penukaran (maksimum $n$ kali swap).
Insertion Sort O(n) O(n²) O(n²) O(1) Stabil, adaptif tinggi untuk data yang hampir terurut (nearly sorted).
Quick Sort O(n log n) O(n log n) O(n²) O(log n) Tidak stabil, sangat cepat pada cache prosesor, worst-case jika pivot buruk.
Merge Sort O(n log n) O(n log n) O(n log n) O(n) Stabil, performa konsisten di semua kasus, membutuhkan array memori tambahan.
lightbulb Kapan Memilih Insertion Sort?

Ketika dataset berukuran kecil ($n < 30$) atau data telah terurut sebagian. Memiliki overhead komputasi paling minim.

speed Keunggulan Quick Sort

Memiliki faktor pengali konstan terkecil dibanding Merge Sort dan tidak memerlukan alokasi memori tambahan $O(n)$ pada heap.

psychology Mengapa Merge Sort Penting?

Pilihan utama bila kestabilan posisi elemen kembar wajib dipertahankan, serta ideal untuk external sorting (seperti linked list atau disk data).
